# Автобусы 150 и 170с: Богатырёво ↔ Малиновка (Космонавтов)

Семейный трекер расписания (веб-приложение PWA + Telegram-бот) для маршрутов:
- **🏠 ➔ 🏙️ В Город:** д. Богатырёво (ул. Полесская, 7) → ост. «Богатырёво» → ост. «Ст. м. Малиновка»
- **🏙️ ➔ 🏠 Домой:** Малиновка (Космонавтов) → ост. «Ст. м. Малиновка» (для 170с — ProStore) → ост. «Богатырёво»

---

## Часть 1. Публикация веб-приложения на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `bogatyrevo-bus`).
2. Загрузите туда все файлы из этой папки (файл `bot_config.json`, если вы его создали, автоматически игнорируется через `.gitignore` и на GitHub не попадёт).
3. В репозитории на GitHub откройте **Settings → Pages**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт появится по адресу:
   `https://<ваш-логин>.github.io/<название-репозитория>/`
5. Отправьте эту ссылку жене и детям:
   - **iPhone (Safari):** кнопка «Поделиться» → «На экран „Домой“».
   - **Android (Chrome):** меню `⋮` → «Установить приложение» (или «Добавить на гл. экран»).

> **Автообновление на GitHub:** в папке `.github/workflows/update-schedule.yml` уже настроен скрипт, который сам каждую ночь и утро (по Минску) проверяет и обновляет `schedule_data.js` без лишних холостых коммитов. Чтобы он работал, включите права записи в **Settings → Actions → General → Workflow permissions → Read and write permissions**.

## Часть 2. Запуск Telegram-бота на домашнем Windows мини-сервере (24/7)

1. Установите **Python 3** на Windows-сервер (при установке обязательно поставьте галочку **Add Python to PATH**).
2. Скопируйте эту папку на мини-сервер (например, в `C:\BusBot`).
3. Создайте бота в Telegram через `@BotFather` (`/newbot`) и скопируйте токен.
4. Скопируйте `bot_config.example.json` и переименуйте копию в `bot_config.json`. Впишите внутрь:
   ```json
   {
     "telegram_bot_token": "123456789:ABC...",
     "web_app_url": "https://maxtor8.github.io/bogatyrevo-bus/"
   }
   ```
   *(Если указать `web_app_url`, у бота внизу появится кнопка для открытия этого веб-приложения прямо внутри Telegram!)*
5. Чтобы работала кнопка **«🔔 Напомнить выйти в Telegram»** прямо с сайта — укажите username вашего бота в файле `site_config.js` (без символа `@`).
6. Запустите **`start_bot.bat`** двойным кликом — бот сразу начнёт отвечать в Telegram и присылать напоминания (за 5 мин до выхода и в момент выхода).

### Автозапуск 24/7 на Windows:
1. Нажмите `Win + R`, введите `shell:startup` и нажмите Enter.
2. Создайте там ярлык на файл `start_bot.bat` — бот будет запускаться сам после перезагрузки Windows.
3. *(Не обязательно, так как бот теперь сам обновляет базу в 06:00 утра)* При желании в **Планировщике заданий Windows** можно также настроить запуск `update_schedule.bat`.
